# BW-APP — Beauty World Staff Platform

A multi-app platform for Beauty World's four retail locations. Each little app lives
under one roof: staff only see what applies to them; managers with credentials see
their crew across every store.

**App #1 — Shift Task List** is the first piece (this prototype). More apps follow.

---

## App #1: Shift Task List

Per **location**, per **day (Mon–Sun)**, per **shift (morning / afternoon)**, staff work
a checklist and sign off each task. Every sign-off is stamped with **who** and **when**.

### What's in the prototype (`index.html`)
- 4 locations · Mon–Sun · morning & afternoon shifts
- **Staff view** — pick your name, work your checklist, tap to sign off (name + timestamp), live progress
- **Manager view** (PIN-gated) — today's completion across all 4 stores/both shifts, drill in to see who did what and when
- **Checklist editor** — managers add/edit/remove tasks per day + shift, or apply one list to all 7 days
- Works offline, saves to the device. No install, no account — open the link on any phone/tablet.

> Prototype note: data is stored on the single device only. Cross-location sync,
> real logins, and the Connecteam schedule feed come in the hosted version (below).

## Connecteam integration — feasibility (researched Aug 2026)

Goal: **no double entry.** The task app should read Connecteam's schedule and give the
day's checklist to whoever is actually scheduled at each store/shift — and only ping them.

**Verdict: possible.** Connecteam has a public REST API (`api.connecteam.com`):
- **Get shifts** → each shift's assigned employee, start/end time, and job/location.
  Morning vs. afternoon is derived from the shift start time.
- **Users** → employee ID, name, phone → lets us notify only the scheduled person.
- **Webhooks** → real-time schedule changes, so re-assignment is automatic (no polling).
- **Auth**: `X-API-KEY` header; key generated by the account **owner** under
  Settings → API keys.

**The one gating requirement:** API access is included only on Connecteam's
**Expert plan (~$119/mo)** or higher. Basic/Advanced plans do not expose the API.

**How to verify:** log into Connecteam as the owner → **Settings → API keys**. If you can
generate a key, we're clear to build the integration. If that tab is absent, the plan
would need to be Expert or above.

_Sources: Connecteam developer docs (`developer.connecteam.com`), Connecteam Help Center, published pricing tiers._

## Roadmap

**Phase 1 — Task List app (in progress)**
Prototype front-end complete. Staff + manager views, sign-off, editable checklists.

**Phase 2 — Hosting + accounts + sync**
Backend + database so all 4 stores share data live; staff & manager logins; manager
sees crews across locations. (Requires a host — small setup, possible small monthly cost.)

**Phase 3 — Connecteam schedule feed**
Pull the day's schedule, auto-assign each store/shift checklist to the scheduled
employee, and notify only those people (in-app or SMS). Webhook keeps it in sync.

**Phase 4 — More apps under the same roof**
The task list is app #1; the platform is built to add more.

## Run the prototype
Open `index.html` in any browser, or serve locally:
```
python3 -m http.server 8000   # then visit http://localhost:8000
```
Demo manager PIN: **1234**. Store and staff names in `index.html` are placeholders — rename them to your real locations and team.
